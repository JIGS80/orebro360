# Örebro360

Örebro i siffror: öppen data om Örebro kommun, samlad och förklarad.

Det här arkivet innehåller den färdiga webbplatsen (statiska sidor, `assets/` och `data/`). Den publiceras med GitHub Pages och uppdateras en gång i månaden med nya siffror.

- Sidorna läser sin data från `data/*.json`.
- Allt finns också som CSV för Excel i `data/csv/`.
- Källor och villkor: se sidan Om sidan (`om.html`).

Fristående sida, inte en tjänst från Örebro kommun.
